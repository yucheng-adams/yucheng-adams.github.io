访问一个网站时，遇到打不开、连接超时或部分内容无法加载，并不一定是电脑出了问题。原因可能来自网站本身、域名解析、网络线路，也可能来自所在网络的访问限制。

“科学上网”是一个通俗说法，通常指借助代理、VPN 等工具，改变网络流量的传输路径，从而访问原本无法直接连接的资源。它不是某一种软件，也不等同于购买一个“VPN App”。

这篇文章面向没有网络技术基础的读者：先弄清楚机场与客户端的关系，再完成第一次连接，最后了解安全使用和其他网络配置方案。

> 资料核对日期：2026 年 9 月 16 日。软件界面、商店上架情况和服务质量可能变化。文中的客户端入口来自项目文档或应用商店；机场候选未经过本文作者的实际线路测试，不构成稳定性或隐私保证。

## 最简单的模式｜机场 + 客户端

对采用订阅式代理服务的人来说，可以先记住这个组合：

**机场提供连接资源，客户端负责使用这些资源。**

一般来说，你只需要下载一个代理客户端（如 Clash Verge Rev、v2rayNG），再找一家支持该客户端的机场，注册账号并开通套餐。把机场提供的订阅链接导入客户端，选择一个可用节点，然后开启代理。

电脑端通常开启“系统代理”（System Proxy），手机端则点击连接，并允许系统添加 VPN 配置。最后，打开你想访问的网站试一下——能正常访问，恭喜你 🎉，大功告成！

#### 第一次连接，按这个顺序做

1. 根据设备选择一个客户端，确认能够从官方入口安装。
2. 确认服务商提供该客户端支持的订阅格式和协议，再选择试用或短期套餐。
3. 在服务商账户中复制对应客户端的订阅链接。
4. 在客户端导入订阅，更新配置，并选中一个节点。
5. 启用系统代理（System Proxy）或客户端的连接开关；日常使用规则模式就可以。
6. 打开实际需要访问的网站，检查页面、图片和登录功能是否正常。

> ##### TIP
> **购买客户端和购买线路通常是两笔不同的费用。** 付费客户端不一定包含节点，免费客户端也不意味着线路免费。

## 什么是机场｜选择合适的机场

机场通常把多条代理线路打包为订阅服务。套餐可能按月度流量、有效期、连接设备数或速率限制计费。

挑选时，最重要的不是“有多少国家的节点”，而是：**在你自己的网络、常用时段和实际用途下，能否持续工作。**

### 付款前检查什么

| 项目 | 具体检查方法 |
| --- | --- |
| 客户端兼容性 | 是否明确支持你的设备、客户端和订阅格式 |
| 流量与有效期 | 流量何时重置，套餐何时到期，剩余流量是否结转 |
| 流量倍率 | 某条线路使用 1 GB，是否会按超过 1 GB 扣除额度 |
| 设备与连接限制 | 是否允许手机与电脑同时使用，共享是否违反套餐规定 |
| 实际体验 | 在常用网络和晚间等常用时段测试网页、视频或会议 |
| 售后与退款 | 是否有明确工单入口、故障公告、试用和退款条件 |
| 运营透明度 | 能否找到服务条款、隐私说明和可核实的运营信息 |

不要只看一次测速。“延迟低”表示响应往返较快，不等于下载速度高，也不等于会议不掉线。“专线”“原生 IP”“解锁”等宣传词同样不能替代实测。

购买前先明确你的用途。例如，看文档关注打开速度；视频会议关注连续稳定性；访问特定平台还要确认该平台自身的地区和账户要求。换一个出口 IP，并不会自动改变账户资格。

### 推荐的机场：先区分候选与实测推荐

本文目前没有足够的独立实测依据，把某一家机场写成“稳定可靠的首选”。直接复制带返佣的排行榜，会让读者把营销排名误认为质量评估。

一个可以进一步核查的候选是 **狗狗加速**：Clash Verge Rev 的官方快速入门文档使用它演示订阅导入，文档中的跳转地址带有推广特征。这个事实只能证明它出现在教程中，**不能证明它在你的网络里稳定，也不能证明它的隐私承诺经过审计**。[查看教程中的演示来源](https://www.clashverge.dev/guide/quickstart.html)。

如果考虑这个候选，仍应自行核实当前官方入口、套餐、条款与售后，再进行短期测试。本文不提供未经核实的备用网址，也不把教程推荐位视为作者实测背书。

对初学者，我更明确的购买建议是：**先试用，不能试用就选择可承受损失的短期套餐；通过测试后再决定是否续费。** 不要为了年付折扣，提前承担尚未验证的长期服务风险。

测试时至少记录以下信息，避免只凭“感觉挺快”下结论：

- 测试日期、所在地区、运营商，以及使用 Wi-Fi 还是移动网络。
- 具体节点、测试时段、目标网站和客户端版本。
- 是否频繁重连，图片和视频是否正常，实际工作能否完成。
- 售后遇到问题时如何响应，而不只是购买前回复有多快。

如果未来在文章中加入更多具名推荐，应同时公布测试条件、缺点、最后复测日期，以及是否存在返佣或赞助关系。

## 选择合适的客户端

先选一个与套餐兼容的客户端，完成连接后再学习高级功能。初学阶段不需要同时安装多款软件。

### 按设备选择

| 设备 | 可考虑的客户端 | 选择理由与注意事项 |
| --- | --- | --- |
| Windows、macOS、Linux | Clash Verge Rev | 图形界面适合管理订阅与分流；确认服务商提供兼容的 Clash/Mihomo 配置 |
| Android | v2rayNG | Android 代理客户端；需要匹配它支持的节点协议和订阅格式 |
| iPhone、iPad | Shadowrocket | 支持规则代理；应用付费与线路费用分开，商店可用性以账户地区为准 |
| 希望进一步学习配置的用户 | sing-box 官方图形客户端 | 先阅读对应平台文档，确认配置格式与版本要求，不建议直接照搬其他客户端配置 |

下载入口应优先使用 [Clash Verge Rev 官方文档](https://www.clashverge.dev/guide/quickstart.html)、[v2rayNG 官方仓库](https://github.com/2dust/v2rayNG)、[Shadowrocket App Store 页面](https://apps.apple.com/us/app/shadowrocket/id932747118) 和 [sing-box 官方客户端目录](https://sing-box.sagernet.org/clients/)。不要仅凭软件名称相同，就信任搜索广告中的下载站。

以下步骤说明操作流程；菜单名称可能随版本和语言变化。订阅格式不匹配时，优先向服务商获取正确格式，不要把私人订阅上传到来历不明的在线转换网站。

### 电脑：Clash Verge Rev

1. 从官方文档进入下载页面，安装适合自己操作系统和处理器的版本。
2. 在机场后台复制兼容 Clash/Mihomo 的订阅地址。
3. 打开客户端的订阅管理页面，粘贴地址并导入；确认配置已下载并被选中。
4. 在代理页面选择规则模式，并在相关策略组中选中可用节点。
5. 打开系统代理，使用浏览器访问目标网站。
6. 如果浏览器正常，但某个软件仍无法连接，再查看它是否支持系统代理，并按官方说明考虑启用 TUN。

系统代理通常适合浏览器等遵循系统代理设置的软件；TUN 通过虚拟网络接口处理流量，可以覆盖更多应用，但也可能涉及权限、路由和其他网络软件的兼容问题。[官方快速入门说明](https://www.clashverge.dev/guide/quickstart.html)。

### Android：v2rayNG

1. 从官方仓库的 Releases 下载适合设备的安装包，按系统提示完成安装。
2. 在订阅分组或订阅设置中添加名称与兼容的订阅地址，保存后更新订阅。
3. 确认节点列表出现内容，选择一个节点。
4. 启动连接，并允许 Android 的 VPN 连接请求。
5. 打开目标网站验证；如需部分应用直连，再学习客户端的路由或分应用设置。

不同订阅可能只包含节点，不包含完整的分流规则。不要假定导入后一定会自动做到“国内直连、国外代理”。项目说明和下载入口见 [v2rayNG 官方仓库](https://github.com/2dust/v2rayNG)。

### iPhone、iPad：Shadowrocket

1. 在自己的 App Store 账户可用地区确认应用是否上架，下载安装。
2. 从服务商后台使用对应的导入入口，或按当前版本的添加订阅流程填入订阅地址。
3. 更新订阅，选择一个可用节点。
4. 启动连接，按系统提示允许添加 VPN 配置。
5. 检查全局路由设置：使用“配置”一类模式时，需要同时确认规则配置可靠且已启用。
6. 打开目标网站测试；若页面正常但某项服务失败，继续检查节点和分流规则。

Shadowrocket 的商店说明明确指出：软件本身不包含代理服务或服务器资源，需要用户提供配置。[查看应用说明](https://apps.apple.com/us/app/shadowrocket/id932747118)。

### 规则、全局、直连怎样选

| 模式 | 含义 | 常见用途 |
| --- | --- | --- |
| 规则模式 | 按配置决定连接走代理、直连或被拒绝 | 配置可信且正确时，适合日常使用 |
| 全局代理 | 客户端接管的连接主要交给选定代理策略处理 | 临时判断问题是否出在分流规则 |
| 直连模式 | 客户端接管的连接直接访问 | 临时排查代理线路问题 |

**“全局”描述的是客户端处理流量的策略，不保证整台设备的所有流量都被接管。** 系统代理、TUN、应用排除项、DNS 和 IPv6 等设置都会影响实际覆盖范围。

### 连不上时，按顺序排查

| 现象 | 优先检查 |
| --- | --- |
| 所有网站都打不开 | 暂停代理后检查本地网络；客户端退出后是否残留系统代理设置 |
| 订阅导入失败 | 地址是否完整、是否过期、格式是否匹配；订阅服务器是否可访问 |
| 节点全部超时 | 套餐是否到期或用完流量；更新订阅；查看服务商故障公告 |
| 只有一个节点不能用 | 更换节点后重试，判断是否为单条线路故障 |
| 浏览器能用，其他软件不能用 | 软件是否遵循系统代理；分应用和 TUN 设置是否影响接管 |
| 网站能打开，但拒绝登录或使用 | 平台的账户、地区或出口 IP 限制，不一定是代理连接故障 |
| 开启后很慢 | 更换节点和时段，对比本地网络；确认是否触发套餐限速 |

每次只改一个设置，记录结果。一次同时修改 DNS、路由、节点和协议，反而会让你无法判断问题在哪。

## 如何安全使用科学上网

### 连接成功，不等于匿名

代理会引入新的信任对象：服务商可能接触连接时间、流量大小和部分目标信息。具体能看到什么，取决于协议、DNS 和网站加密方式。

在正常 HTTPS 连接、证书验证未被破坏的情况下，中间的代理服务商通常不能直接读取网页正文或密码。但登录账户、Cookie 和浏览器指纹仍可能让网站识别你。更换 IP 并不能消除这些关联。[EFF 对 VPN 能力与局限的说明](https://ssd.eff.org/module/vpn.html)。

### 把订阅链接当作密码

订阅链接通常含有访问凭据。泄露后，别人可能获取节点配置、消耗套餐，或触发服务限制。

- 不要将完整链接、订阅二维码或配置文件发到公开论坛、聊天群或 GitHub。
- 求助时遮住令牌、密码、邮箱和节点认证信息；日志也应检查后再分享。
- 不要把订阅交给不可信的在线转换工具。
- 如果泄露，在服务商后台重置订阅，并询问是否需要同时重置节点凭据；只删除公开截图并不足以撤销已经泄露的凭据。

### 不要随意安装证书或脚本

普通代理连接通常不需要你安装并信任陌生的根证书。若教程要求开启 HTTPS 解密、安装根证书或运行来源不明的脚本，应先弄清用途。

HTTPS 解密会改变信任边界，让相应工具有机会读取原本加密的内容。对于只想访问网页的初学者，没有必要为了“更强功能”默认打开它。

### 保护账户，保持配置简单

为重要账户使用独立密码并启用多因素认证；保持操作系统和客户端更新。不要使用陌生人共享的 Apple ID 登录设备，也不要为了安装客户端而安装来源不明的描述文件。

不要默认代理断开后设备就会停止联网。规则模式中的直连连接本来就可能绕过代理；是否阻止连接回落，需要具体功能和设置支持。

工作设备应先遵循组织的网络与数据要求。涉及合同、报销、客户资料等内容时，不应为了方便而自行改变组织要求的访问路径。

## 其他的翻墙方案

“机场 + 客户端”只是其中一种组合。其他方案解决的需求不同，不能简单按“高级程度”排名。

### 一体化商业 VPN

由同一服务商提供账号、应用和连接线路，通常省去手动管理节点订阅的步骤。适合更重视操作简便的人。

需要分别判断两件事：**隐私保护如何，以及在你的网络中是否能连接。** 前者做得好，不代表后者一定成立。购买前仍应阅读条款并短期测试，不要仅凭“全球可用”的广告做决定。[VPN 选择参考](https://ssd.eff.org/module/vpn.html)。

### 自建代理或 VPN

自己租用服务器、安装服务端，再通过客户端连接。它提供更多配置控制权，但也意味着你要负责更新、安全设置、故障排查和服务器成本。

自建并不自动更匿名、更稳定或更便宜；云服务商和服务器出口仍然是需要考虑的信任与可用性环节。对初学者而言，更适合作为后续学习项目。

### Tor Browser

Tor Browser 通过 Tor 网络访问网站，适合有特定隐私需求的浏览场景。它主要保护浏览器内的活动，并不会自动接管整台设备。

当直接连接受阻时，Tor 提供网桥和可插拔传输机制辅助连接，但是否有效取决于实际网络，速度也可能受影响。应使用 [Tor 官方的连接受阻帮助](https://support.torproject.org/tor-browser/circumvention/unblocking-tor/)，避免照搬过时的网桥教程。

### 组织提供的远程访问服务

如果目的是访问公司或学校内部资源，优先使用组织提供的 VPN、远程桌面或其他授权入口。这些服务通常面向指定资源，未必提供通用互联网出口。

对第一次使用的人，今天可以先完成一件事：**确认设备和客户端兼容，使用一个短期套餐，按本文步骤连通真正需要的网站。** 连通后再优化规则、成本和备用方案，比一开始比较几十款工具更有效。
