### 连不上代理时，顺序排查建议

| 现象 | 优先检查 |
| --- | --- |
| 所有网站都打不开 | 暂停代理后检查本地网络；客户端退出后是否残留系统代理设置 |
| 订阅导入失败 | 地址是否完整、是否过期、格式是否匹配；订阅服务器是否可访问 |
| 节点全部超时 | 套餐是否到期或用完流量；更新订阅；查看服务商故障公告 |
| 只有一个节点不能用 | 更换节点后重试，判断是否为单条线路故障 |
| 浏览器能用，其他软件不能用 | 软件是否遵循系统代理；分应用和 TUN 设置是否影响接管 |
| 网站能打开，但拒绝登录或使用 | 平台的账户、地区或出口 IP 限制，不一定是代理连接故障 |
| 开启后很慢 | 更换节点和时段，对比本地网络；确认是否触发套餐限速 |

每次只改一个设置，记录结果。一次同时修改 DNS、路由、节点和协议，反而会让你无法判断问题在哪。
